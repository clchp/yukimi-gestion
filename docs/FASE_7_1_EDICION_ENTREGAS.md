# Fase 7.1 — Corrección de entregas pendientes

Las entregas pueden corregirse mientras estén en **Pendiente de indicaciones**, **Acumula almacén** o **Pendiente de despacho a agencia**.

Se permite corregir método, operador, dirección, fecha planificada, tracking inicial, costo, responsable del costo, notas y cantidades. El motivo es obligatorio y todos los cambios quedan auditados. Los productos retirados se conservan como líneas inactivas; no hay borrado físico.

Después de entregar a la agencia, iniciar reparto, entregar al cliente o cancelar, la ficha queda bloqueada. En esos estados corresponde usar el flujo de cancelación o una operación compensatoria, no reescribir la historia.
